# Gandom Market

نسخه اولیه وب‌اپ گندم با Next.js برای مشتریان خانگی و همکاران بازار طلا و نقره.

## صفحات
- `/` صفحه اصلی
- `/gold` گندم گلد
- `/silver` گندم سیلور
- `/register` ثبت‌نام اولیه

## اجرا
```bash
npm install
npm run dev
```

قیمت‌های این نسخه نمایشی هستند و هنوز به سرویس واقعی قیمت، OTP، KYC، Wallet و Trade متصل نشده‌اند.
